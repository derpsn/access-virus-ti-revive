# Audit 2026-11-17: fix list

Read-only whole-repo audit (four parallel audits: broker, device layer, plug-in, installers/CI) on round-0.8.42
(3c45c5a). Nothing was run on hardware; findings are reasoned from the code. A finding is **done** only when
`/ponytail:ponytail-review` confirms the fix. Each fix: failing test first (TDD), then the code, then review.
Findings that touch the device need an evidence entry before they are called confirmed (rule 3).

Status: `open`, `in progress`, `done` (reviewed), `dropped` (with the reason).
